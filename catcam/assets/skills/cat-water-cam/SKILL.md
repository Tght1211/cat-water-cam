# 猫咪喝水轨助手

仅处理 `cat-water-cam` 中**已经被确认喝水**的录像。目标是定位视频里真正舔水的区间，排除靠近、嗅闻、抬头、停顿和离开，生成可在网页检查的喝水轨草稿。服务默认 `http://127.0.0.1:8000`；外部 Agent 自行使用它已有的视觉模型，项目无需配置其 API Key 或安装 Codex SDK。

## 工作方式

运行本 Skill 自带的 `scripts/catcam_materials.py`（Python 3.10+；抽帧需要 ffmpeg）。命令中的脚本路径按本 Skill 实际安装位置解析。

1. `python3 scripts/catcam_materials.py list --limit 12`：只列已确认喝水素材；需要更多时传返回的 `--cursor`。不要改为扫描待复核或负样本。
2. `info 视频名` 取得原视频相对时长和版本指纹；`prepare 视频名 --out 工作目录 --start 0 --seconds 30` 准备有时间戳的连续画面。长视频按相邻时间窗逐段查看，可在同一输出目录继续 `--start 30`，缓存原视频不重复下载。默认每 0.5 秒一帧；边界不清时使用更短时间窗和 `--step 0.25`。
3. 用 Agent 的图像查看能力观察这些帧，**必须实际查看画面**。记录真正舔水的多段区间、看不清的区间以及已查看范围。返回原视频从 0 起算的秒数，不使用摄像头叠加时钟。模型没有看图能力时说明限制，不伪造识别结果。
4. 根据 manifest 写独立的建议 JSON，再运行 `propose 建议文件.json`。具体字段和长视频合并方式见 [建议格式](references/proposals.md)。接口核对已确认状态、素材指纹和范围；提交只产草稿，不覆盖人工轨道、标签或训练状态。重复提交相同建议不会新增重复任务。
5. 报告建议编号、已分析范围、明确喝水秒数与不确定范围，提示用户在“素材任务”导入并保存。用户确认保存后项目才使用区间并集更新时长；部分视频未分析的范围保留未知，不能声称完成整片。

## 判定与统计

- 猫已经被确认喝水，本 Skill 不重新裁定是否喝水，不驳回或改成负样本。发现结果与已确认结论明显冲突时报告给用户，不改标签。
- 不根据出水开关、画面亮度或“猫在碗边”推断舔水。遮挡、动作不清楚标为 `unknown`，不能当成明确停顿。0.5 秒抽帧不提供逐帧精度。
- 同一视频的多段舔水区间按并集计时，重叠不重复计算。原有人工区间是参考，不是需要无条件保留或抹掉的真值；只提交建议，让用户决定是否替换。
- 如需水量估值，读取 `calibration` 的 `ml_per_second`，仅以有效上一周期校准值乘动作秒数。校准缺失、区间未确认或画面不确定时说明不足，不套用固定 30ml，不把视频整长当喝水时长。
- 不启动模型训练、不激活模型、不删除录像，也不读取项目配置中的第三方凭据。素材仍由项目服务本机/内网访问；Agent 使用外部视觉服务时，按用户选定的 Agent/服务及授权范围处理，不另换目的地上传。

## 连接与兼容

`--base` 或 `CATCAM_URL` 指定本机/内网地址；若网页设了访问密码，用环境变量 `CATCAM_PASSWORD` 登录，勿把密码放进命令行、建议文件或输出。没有访问权限时停止，不关闭认证。该 Skill 适用于能读取 SKILL.md、运行 Python/ffmpeg 并查看图片的 Agent；不保证每个 Agent 产品的安装入口或视觉能力一致。
