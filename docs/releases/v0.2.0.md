# 喵喵水站 v0.2.0

这是第一个包含真实演示素材和开箱即用本地视频模型的公开版本。

## 主要更新

- README 全面更新，首屏加入实际运行界面与真实采集的小猫喝水视频。
- 开源预训练 `S3D + 分类头` 模型：57 段喝水、462 段没喝，验证集 top1 89.1%。
- 全新安装首次启动会自动登记内置模型，并以安全的 `shadow` 模式运行；已有模型库不会被覆盖。
- 模型优先复核：默认只把没有模型结果或概率不确定的片段交给人工处理。
- 人工改判作为纠错数据进入下一轮训练，可在网页一键训练新模型。
- 本地视频模型支持热切换，点击“设为生效”后立即用于下一段录像，无需重启采集进程。
- 恢复 OpenAI 兼容外部视觉模型裁判路径；`gate` 模式保持全本地，不上传画面。
- 增加 `/api/audio/status`，可检查麦克风进程、缓冲时长和音轨合成成功/失败次数。
- 视频审核页面改为紧凑网格，同屏处理更多候选片段。
- 增加 MIT License，代码、仓库演示素材和预训练分类头均可按许可证使用。

## Release 资产

- `cat-drinking-demo.mp4`：项目真实采集并由人工确认的小猫喝水视频。
- `catcam-pretrained-s3d-head-v11.npz`：仓库内置的预训练视频分类头。
- `SHA256SUMS.txt`：上述资产的 SHA-256 校验值。

## 使用方式

```bash
git clone https://github.com/Tght1211/cat-water-cam.git
cd cat-water-cam
python3 -m venv .venv
.venv/bin/pip install -e .
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m catcam
```

首次运行会自动安装内置分类头。S3D 主干由 torchvision 首次推理时下载约 30 MB。

## 注意事项

- 预训练模型来自特定猫、饮水机、机位与光照，应先使用 `shadow` 模式评估，再决定是否切换 `gate`。
- 外部视觉模型会上传抽取帧；希望保持纯本地时，请不要填写 `ai_api_key`。
- macOS 录音需要授予终端麦克风权限；可通过 `/api/audio/status` 查看真实运行状态。
